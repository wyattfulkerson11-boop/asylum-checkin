Class Check-In iPad

Setup takes about 10 minutes, once. After that students just tap their name.

Set up the iPad (once)

  1. Connect to the gym Wi-Fi. Open Safari (the blue compass, not Chrome) and type this address exactly:
    wyattfulkerson11-boop.github.io/asylum-checkin/
    You should see the Asylum logo and "Asylum Martial Arts."
  2. Tap the Share button (square with an arrow pointing up) → Add to Home Screen → name it Check In → Add.
  3. Close Safari. Tap the new Check In icon and leave it open for a minute on Wi-Fi. That lets it save itself so it still opens if the Wi-Fi drops.
  4. Settings → Display & Brightness → Auto-Lock → Never, and leave the iPad plugged in.
  5. Optional, to stop kids leaving the app: Settings → Accessibility → Guided Access → On, set a passcode. Open Check In, triple-click the top button → Start. Triple-click again and enter the passcode to get out.
Only ever open it from the Check In icon. Safari and the icon keep separate lists — names added in Safari won't show up in the icon.

Students

  • First time: tap I'm new, type first and last name, Save. Only once — after that the name is a button.
  • Every class: tap your name → tap every class you're here for → Check in. It remembers last time's classes, so a regular is two taps.
  • Parent with several kids: tap Several kids, tap each name, then Check in.
  • Wrong name? Tap Not me. A name with a ✓ has already checked in today; checking in again just adds classes.

Coaches

Tap Coach (bottom right) and type the coach PIN. Get the PIN from Wyatt — it's never written down here. The coach screen goes back to check-in on its own after 2 minutes.

  • Roster: pick a day → Share PDF → AirDrop, Mail, Messages or Print. Grouped by class.
  • Spreadsheet: pick a from and to date → Share spreadsheet. Opens in Excel or Numbers.
  • Classes: one class per line → Save classes. These are the buttons students see.
  • Students: Rename fixes a typo. Remove takes a name off the check-in screen; past attendance is kept.

Good to know

Names and attendance live on this iPad only. There is no copy anywhere else. Share the spreadsheet to yourself once a month as a backup.
  • Don't delete the Check In icon and don't erase the iPad — that erases the names and attendance with it.
  • It works without Wi-Fi. Sharing a PDF by Mail or Messages needs Wi-Fi; printing and AirDrop don't need the internet.
  • If it ever says "Saved data could not be read", or anything else looks wrong, stop and tell Wyatt.
